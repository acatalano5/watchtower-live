WATCHTOWER - GitHub Pages direct upload package

IMPORTANT: Extract this ZIP first. Upload the CONTENTS of this folder to the root of your GitHub repository. Do not upload the ZIP itself.

Expected repository root:
  index.html
  .nojekyll
  assets/app.js
  assets/styles.css
  data/events.json

For GitHub Free:
1. Create a PUBLIC repository (example: watchtower-live).
2. Add file -> Upload files.
3. Drag the extracted files/folders above into the repository root and commit them to main.
4. Settings -> Pages.
5. Source: Deploy from a branch.
6. Branch: main, Folder: /(root).
7. Save.

This package is the deployable front end only. It does not contain the private collector/build scripts or GitHub workflow from the development repository.

NOTE: Because this version is direct/static, data/events.json will not automatically refresh unless it is replaced by a later build or another automation is added.
